# College Website Project

A responsive and modern college website developed using **HTML, CSS, JavaScript, and Flask-ready structure**. The project provides an attractive user interface for presenting college information, courses, facilities, departments, and other important sections in an organized way.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Modern landing page with attractive UI
* Multiple web pages with consistent navigation
* Clean and optimized CSS styling
* Reusable components and structured layout
* Flask-ready folder structure
* User-friendly interface
* Interactive sections using JavaScript

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Responsive Web Design

### Backend Ready

* Python Flask (integration ready)
* Jinja2 Templates (for Flask conversion)

## 💻 Installation and Setup

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to Project Folder

```bash
cd College-Website
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

Activate environment:

**Windows**

```bash
venv\Scripts\activate
```

**Linux/Mac**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Flask Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000/
```
